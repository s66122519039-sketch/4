# งานสอบ เว็บคำนวณปริมาตร 10 รูปทรง

แตก ZIP ทั้งหมด แล้วเปิด START-HERE.html เพื่อเลือกรูปทรง

แต่ละหน้ามีภาพตัวอย่าง ภาพสูตร และแบบฟอร์มคำนวณเหมือนเดิม
- ลิงก์ HTML, script.js และ styles.css เปิดหน้า Source Code สำหรับอ่านโค้ด ไม่ดาวน์โหลดไฟล์
- ลิงก์ภาพตัวอย่างและภาพสูตรยังใช้ดาวน์โหลดรูปภาพ
- กด “กลับหน้าคำนวณ” จากหน้า Source Code เพื่อกลับไปกรอกค่า
- ใช้งานได้แบบออฟไลน์ ไม่ต้องติดตั้งไลบรารี

หน้า source-html.html, source-js.html และ source-css.html แสดงเนื้อหาตรงกับไฟล์จริง ณ วันที่จัดชุดนี้ หากแก้โค้ดภายหลัง ต้องปรับหน้าแสดงโค้ดให้ตรงกันด้วย
image-downloads.js เป็นไฟล์ช่วยดาวน์โหลดรูปภาพแบบออฟไลน์ ส่วนสูตรคำนวณอยู่ใน script.js
